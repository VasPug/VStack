# VStack

Claude Code skills I actually use.

## Skills

| Skill | What it does |
|---|---|
| [`plan-week`](skills/plan-week/SKILL.md) | Reads a week of your commits, PRs, team chat and last week's goals, interrogates you about what the week is for, then writes a short list of committed outcomes — each with a date and someone else who checks it. |

## Install

```bash
git clone https://github.com/VasPug/VStack.git
ln -s "$PWD/VStack/skills/plan-week" ~/.claude/skills/plan-week
```

Then `/plan-week`, or just say "plan my week".
